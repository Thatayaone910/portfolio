# portfolio
A clean, responsive portfolio website for software developers, featuring:
- **Matrix-themed design** with animated falling code characters
- **Fully responsive** layout that works on all devices
- **Interactive elements** with smooth animations and transitions
- **Skills visualization** with animated progress bars
- **Project showcase** with hover effects
- **Contact form** with validation
- **Developer avatar** using DiceBear API

**Technologies:** Pure HTML5, CSS3, Vanilla JavaScript (no frameworks/libraries)
